# Munissa Sari Mahardika — Portfolio Site

Plain HTML/CSS site. No build tools, no dependencies to install — open the
files, edit the text, save, and re-upload.

## Files
- `index.html` — Home page (about, experience, skills, education, contact)
- `projects.html` — Portfolio / case study page
- `style.css` — All colors, fonts, and layout rules
- `README.md` — This file

## To change text
Open `index.html` or `projects.html` in GitHub's editor (pencil icon) or any
text editor, find the sentence you want to change, edit it, and save.

## To change colors or fonts
Open `style.css` and edit the values inside `:root { ... }` at the top of the
file. Every color and font on the site is defined once there.

## To add a new project
Copy one `<div class="project-card"> ... </div>` block in `projects.html`,
paste it where you want the new project to appear, and edit the text inside.

## Hosting
This site is built to run on GitHub Pages (free, no server needed) and is
plain enough to move to any other static host or institutional server later
— just copy the three files.
